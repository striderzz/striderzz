Software engineer focused on **agentic AI systems**, **MLOps** and **full-stack development**. I design LLM agents
and the services around them, train and ship ML models, and build the web apps that put them in front of users.
M.S. in Computer Engineering from **The University of Texas at Dallas** (2024 - Aug 2026).

### What I build

**Agentic AI systems.** Multi-agent workflows and ReAct agents in LangGraph, tool calling, RAG pipelines,
structured outputs, and multi-provider LLM layers (OpenAI, Gemini, Anthropic, local models through Ollama).

**MLOps.** Models trained in PyTorch and scikit-learn, served behind FastAPI and Flask APIs, containerised with
Docker and deployed on AWS, with automated tests around them.

**Full-stack development.** Python backends (FastAPI, Flask, Django) and JavaScript front ends (React, Express),
on SQL and MongoDB, through to packaged desktop apps.
